# Мастерская автора

`Студия автора → Мои произведения → Открыть мастерскую → Новая глава`.
Мои произведения — только работы текущего аккаунта. Админская модерация всех
работ находится отдельно. Циклы представлены раскрывающейся группой;
порядок меняется в «Циклы и группы».

## Редактор

Выделите текст и выберите оформление на панели:

- жирный, курсив, подчёркивание, зачёркивание, выделение цветом;
- заголовок, цитата, маркированный/нумерованный список;
- диалоговое окно с именем говорящего, примечание, скрываемый спойлер;
- выравнивание блока и разделитель сцен;
- отмена/повтор, Ctrl/Cmd+B, I, U, Z, Shift+Z / Y.

Сложные блоки открывают диалог с заголовком и содержимым. Предпросмотр
и читалка используют один безопасный обработчик. HTML не исполняется.
Блоки можно править прямо в тексте:

```text
**жирный** *курсив* __подчёркнутый__ ~~зачёркнутый~~ ==выделенный==

:::dialog Анна
— Привет.
:::

:::note От автора
Примечание к сцене.
:::

:::spoiler Развязка
Читатель раскроет этот блок по нажатию.
:::

:::center
Текст по центру.
:::
```

Размер шрифта, интервал, гарнитура и предпросмотр — настройки рабочего места,
а не принудительное оформление текста у всех читателей. Есть режим фокуса,
счётчики знаков/слов, время чтения и цель по словам, скачивание `.txt`.

## Черновики и сохранение

Локальная версия сохраняется после ввода и при уходе со страницы. Ключ
изолирован по аккаунту, произведению и главе. При возвращении редактор
предлагает восстановить версию или удалить её — не подменяет опубликованный
текст молча. Заметки автора хранятся локально отдельно и не публикуются.

«Сохранить черновик» записывает главу в аккаунт. «Опубликовать» требует
подтверждения. При ошибке базы нет ложного сообщения об успехе: текст остаётся
в редакторе и в локальной копии. Можно скачать его отдельным файлом.

Шесть исходных книг Cnizroman не дублируются в редакторе глав: их полный текст
находится в соответствующих HTML-файлах репозитория. В студии меняется
карточка произведения; рядом указана ссылка на исходный текст.

## Расширенные инструменты

Раскройте **«Поиск и замена · шаблоны · импорт · версии · структура»**.

- **Поиск и замена:** Ctrl/Cmd+F, следующий/предыдущий результат, учёт регистра,
  целое слово (включая кириллицу), замена текущего совпадения или всех сразу.
  Поиск буквальный — введённая строка не исполняется как регулярное выражение.
- **Оглавление:** список заголовков с переходом к месту в редакторе;
  три уровня заголовков. Кнопка уровня превращает текущую строку в заголовок.
- **Шаблоны:** сцена, диалог, письмо и стихотворение вставляются в позицию
  курсора. Полноценные диалоговые окна/спойлеры/примечания остаются на панели.
- **Оформление:** выбор цвета текста и подсветки выделенного фрагмента;
  снятие оформления с выделения. Цвета отображаются и в читалке, не только
  в предпросмотре. HTML и произвольный CSS не разрешены.
- **Рабочее место:** тёмная, бумажная и светлая темы; редактор и предпросмотр
  рядом, друг под другом, только текст или только предпросмотр; ширина
  колонки; проверка орфографии средствами браузера. Tab вставляет отступ.
  Настройки запоминаются в этом браузере.

Синтаксис цветов и уровней заголовков:

```text
# Глава
## Сцена
### Подзаголовок
{color:#cc3388}Цветной текст{/color}
{mark:#ffdd00}Подсвеченный текст{/mark}
```

## Импорт и резервные копии

TXT и Markdown загружают текст, JSON — заголовок, текст и приватные заметки.
Максимум файла 2 МБ, текста — 400 000 символов. Импорт заменяет редактор
только после подтверждения и создания локальной версии предыдущего текста.
Содержимое файла не исполняется как HTML/JavaScript.

Экспорт доступен в TXT, Markdown и JSON. **JSON содержит приватные заметки**:
это резервная копия для автора, а не файл для публичной публикации.
Имена файлов транслитерируются для переносимости и сохранения расширения.
Экспорт сам по себе не публикует главу и не записывает её на сервер.

## История версий

Можно дать версии имя, сохранить её, восстановить или удалить. Сначала
создаётся снимок текущего текста, затем восстанавливается выбранная версия.
Перед импортом и восстановлением предыдущий текст не теряется молча.

История раздельная для аккаунта, произведения и главы. При первом сохранении
новой главы её история переносится к полученному ID. Хранится до 8 версий
в пределах 600 000 символов JSON на главу: большие снимки могут сократить
число сохранённых версий. При нехватке места показывается ошибка.

**Это локальные версии:** они не синхронизируются между устройствами и могут
исчезнуть при очистке данных браузера. Для длительного хранения скачайте
JSON и сохраняйте главу в аккаунт. Приватные заметки в читалку не попадают.

## Визуальная мастерская и авторская книга

Редактор теперь открывается в визуальном режиме: выделите текст и нажмите кнопку
оформления. Для исходного формата есть отдельный режим «Разметка».

Палитра «Добавить красивый блок» создаёт сцену, письмо, документ, переписку,
сообщение системы, воспоминание, сон, эпиграф, стихотворение, предупреждение
и раскрываемый вариант. Диалоги, примечания, спойлеры и выравнивание сохранены.
Содержимое редактируется прямо в визуальном поле. Клик по блоку открывает
команды перемещения и удаления; отмена/повтор работает и для этих действий.

В «Оформлении для читателей» — шесть книжных тем, три семейства шрифтов,
размер, интервал, ширина, выравнивание, буквица, заголовки и разделители.
Предпросмотр и читалка используют один обработчик. Изменение стиля главы
применяется ко всему произведению и сохраняется вместе с сохранением главы.
JSON-копия, локальная история и восстановление черновика включают стиль.

Личный вид рабочего места спрятан в отдельные настройки и не меняет книгу.
Поиск/замена и точные инструменты разметки переключают редактор в исходный режим.
HTML из буфера обмена не вставляется: принимается только обычный текст.

Серверные пароли доступны **каждому автору своей истории**, в настройках доступа
после создания карточки. Это не пароль аккаунта. До серверной настройки эта
возможность отключена. Премодерация чужих произведений остаётся обязательной.

Подключение базы и ограничения защиты: [STORY_STUDIO_SETUP.md](STORY_STUDIO_SETUP.md).
В SQL Editor используется один общий файл **STORY_STUDIO_SETUP.sql**.
