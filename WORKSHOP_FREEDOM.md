# Свободная мастерская · v3

Это дополнение к [конструктору страниц](STORY_DESIGN.md), а не замена старого редактора. Все авторы получают одинаковые инструменты; чужие публикации по-прежнему проходят ручную проверку.

## 1. Своя обложка с устройства

1. Войдите → **Студия автора** → откройте своё произведение или создайте новое.
2. В карточке произведения найдите **«Ваша обложка — без готовых шаблонов»**.
3. Нажмите **«Загрузить готовую обложку»** и выберите изображение.
4. Дождитесь сообщения **«Обложка загружена»**. По умолчанию изображение показывается целиком, с собственными пропорциями, без навязанных надписей сайта.
5. При необходимости включите **«Показывать название и автора поверх рисунка»**. Можно поменять размещение картинки, собственные цвета градиента и символ / надпись. Для пустого символа очистите поле.
6. Нажмите **«Сохранить произведение»**. Проверьте страницу произведения и карточку каталога. Если вы не администратор, изменённую обложку читатели увидят только после одобрения произведения.

Поддерживаются PNG, JPEG, WebP, GIF, AVIF, BMP и статический SVG; доступность декодирования зависит от браузера. Результат **статический**: GIF не становится анимированной обложкой. SVG проверяется и растеризуется, а не вставляется в HTML. Исходное изображение — до 12 МБ и 32 млн пикселей; SVG — до 2 МБ. В общую базу отправляется сжатый растровый результат до 1 МБ, не исходные EXIF-метаданные.

## 2. Нарисовать / собрать обложку

1. В том же разделе раскройте **«Нарисовать / собрать свою обложку»**.
2. Выберите размеры холста (256–2000 px по каждой стороне), фон и инструмент: **кисть, ластик, прямоугольник, эллипс, линия, текст, перемещение слоя**.
3. Для текста впишите надпись, выберите шрифт и размер, затем нажмите на холст в месте вставки. Работают встроенные и загруженные вами шрифты.
4. Через **«Изображение новым слоем»** добавьте фотографию или иллюстрацию. Через список **«Слои»** выберите нужный слой; инструментом перемещения перетащите его. Кнопки **«Выше / Ниже»** меняют порядок, **«Удалить слой»** удаляет выбранный.
5. Чтобы изменить уже созданный текст или фигуру, выберите слой, поменяйте параметры и нажмите **«Изменить цвет / текст слоя»**. Доступны отмена и повтор.
6. Нажмите **«Использовать рисунок как обложку»**, затем **«Сохранить произведение»**. Кнопка сохранения произведения также применяет законченный несохранённый рисунок; во время загрузки нужно дождаться её завершения.
7. **«Скачать PNG»** сохраняет готовую картинку. **«Скачать проект со слоями»** сохраняет редактируемый JSON; вернуть его можно через **«Открыть проект»**.

Если открыть произведение на другом устройстве без локального проекта, сохранённая обложка загружается на холст одним изображением: поверх неё можно продолжать рисовать. Исходные отдельные слои из готовой картинки восстановить нельзя — для них нужен JSON-проект. Если обложку изменили на другом устройстве, старые локальные слои не подменяют новую картинку автоматически: для них появляется кнопка **«Восстановить прежний локальный проект»**. Простое сохранение карточки не заменяет новую обложку старым проектом.

Мышь и касания поддерживаются. До 100 слоёв; импорт / экспорт проекта — до 40 МБ. История ограничена по числу состояний и памяти. **В облаке хранится готовая обложка, не редактируемые слои.** Слои автоматически остаются в IndexedDB текущего браузера, но для переноса на другое устройство скачайте JSON-проект. Очистка данных браузера удаляет локальный исходник, не облачную картинку. Проект включает растровые слои, но не двоичные файлы шрифтов: на другом аккаунте загрузите нужный шрифт и назначьте его текстовому слою. Недоступный шрифт заменяется системным с предупреждением.

## 3. Свой файл шрифта

1. В форме произведения откройте **«Авторское оформление»**; в главе — **«Оформление для читателей»**.
2. В начале конструктора нажмите **«Импортировать свой шрифт»** либо раскройте **«6 · Свои шрифты и разделители — импорт файлов»**.
3. Через **«Загрузить шрифт»** выберите **WOFF2, WOFF, TTF или OTF до 2 МБ**. Дождитесь **«Файл готов»**.
4. Файл появится в выпадающих списках основного шрифта и шрифта заголовков; основной шрифт выбирается автоматически. Встроенные варианты не исчезают.
5. Настройте размер, насыщенность, интервалы и прочее → **сохраните произведение / главу**.

Шрифт проверяется настоящим браузерным декодером. Наличие кириллицы зависит от самого файла: если в нём нет нужной буквы, браузер использует запасной шрифт. Некоторые начертания синтезируются браузером. В редакторе главы вариант рабочего шрифта **«Как в оформлении произведения»** показывает авторский шрифт; личный выбор рабочего шрифта не меняет вид для читателя. Публикуйте только файлы, на использование которых у вас есть права.

## 4. Собственный разделитель

1. В начале конструктора нажмите **«Импортировать свой разделитель»** либо в разделе своих файлов выберите **«Импортировать разделитель»**. Поддерживаются те же изображения, что для обложки.
2. После обработки рисунок появится в списке разделителей и живом образце. Сохраните оформление.
3. Для отдельного места главы откройте **«Добавить красивый блок» → «Разделитель сцен»** и выберите свой рисунок. В одной главе могут быть разные разделители.
4. Размер, длина и отступы общего разделителя настраиваются в разделе **«Разделения и свои символы»**.

Обычный статический SVG с фигурами, градиентами, внутренними ссылками и стилями преобразуется в WebP. Скрипты, события, внешние файлы и активные элементы запрещены; для неподдерживаемого SVG экспортируйте PNG в графическом редакторе. На сервере остаётся только растровый файл до 1 МБ.

## 5. Свои диалоги, карточки и настоящие всплывающие окна

1. В редакторе главы раскройте **«Добавить красивый блок»**; найдите **«Диалог»**, **«Всплывающее окно»**, **«Карточка»**, **«Отдельная страница»** или другой из 27 типов.
2. Впишите заголовок и содержимое. Включите **«Свой вид окна / карточки / страницы»**.
3. Задайте фон, текст, акцент, скругление, поля, толщину и тип рамки, ширину, расположение, значок и подпись. Каждый блок может выглядеть по-своему.
4. Нажмите **«Вставить»**. Для изменения готового блока выделите его в визуальном редакторе → **«Настроить блок»**. Это изменяет выбранный блок, не вставляет второй.
5. Сохраните главу. **«Диалог»** находится прямо на странице; **«Всплывающее окно»** открывает настоящее модальное окно кнопкой в читалке, закрывается кнопкой или Escape.

Цвета не проверяются на «достаточный контраст»: одинаковый цвет текста и фона разрешён. Проверяется только корректный формат. Текстовая разметка внутри блоков сохраняется; HTML/JavaScript не исполняются. Настройки доступны и без ручного редактирования разметки.

## 6. Собственный жанр

Поле **«Жанр · выберите или впишите свой»** — обычный ввод с подсказками. Впишите любой жанр до 60 символов, сохраните произведение. После публикации жанр доступен в фильтре каталога. Прежние категории, поиск по названию и группировка циклов остаются.

## 7. Мои файлы, повторное использование и резервные копии

- В разделе своих файлов нажмите **«Мои файлы аккаунта · повторно использовать / удалить»**. Шрифт или разделитель можно добавить в другой свой стиль без повторной загрузки.
- **«Убрать из стиля»** убирает ссылку из текущего оформления, но не удаляет файл из аккаунта. Чтобы освободить место, сначала уберите сохранённые ссылки из произведений / глав и сохраните изменения, затем удалите неиспользуемый файл из аккаунта.
- Сервер не позволяет удалить файл, используемый в сохранённых стилях, обложках, опубликованном тексте или черновиках. Локальные старые JSON-проекты и скачанные файлы сервер не отслеживает.
- Общий лимит аккаунта — **64 файла / 32 МБ** хранимых data URI, включая Base64; это не 32 МБ исходных бинарных файлов. В одном стиле — до 32 шрифтов и 32 разделителей.
- **Обычный JSON стиля** содержит настройки и ссылки на файлы аккаунта. Для переноса между аккаунтами нажмите **«Скачать комплект стиля со своими файлами»**, затем на другом аккаунте **«Открыть комплект с файлами»**. Комплект включает сами шрифты / разделители, получает новые собственные ID при переносе, не содержит текста и заметок. На исходном аккаунте неизменённые файлы повторно используются, не дублируются.
- **Резервная JSON-копия главы** в разделе **«Поиск и замена · шаблоны · импорт · версии · структура»** включает текст, приватные заметки, оформление и файлы шрифтов / разделителей. При импорте в другой аккаунт ссылки в оформлении и разделителях главы заменяются новыми собственными ID. Обложка произведения в эту копию главы не входит. Старые TXT, MD и JSON-копии также читаются. Импорт комплектов / копий — до 40 МБ; лимиты текста главы, заголовка и заметок сохраняются.

Не публикуйте приватную резервную копию главы как общедоступный файл: она намеренно содержит ваши заметки.

## Что остаётся защищённым

- Загруженный файл принадлежит аккаунту. Содержимое неизменяемо: новый вариант получает новый ID, поэтому нельзя незаметно заменить уже проверенную картинку под тем же ID.
- Публичные файлы выдаются только для одобренного произведения: обложка открыта, а шрифты / разделители защищённой истории — после проверки её пароля. Неиспользуемая библиотека стиля и картинки из приватных черновиков читателю не выдаются.
- Черновики и непринятые изменения доступны автору и администратору. Новые обложки и оформление не обходят премодерацию. Исходная серверная проверка пароля и её счётчик попыток не заменены.
- Персональные настройки читалки остаются у читателя. Никакие привилегии администратора, пароли аккаунтов, почта и подключения соцсетей этим обновлением не меняются.

## Техническая установка и тесты

Для уже установленной мастерской v1/v2: **WORKSHOP_FREEDOM_UPGRADE.sql**, эквивалент `supabase/migrations/20261102000500_workshop_freedom.sql`. Для новой установки: базовая схема платформы и актуальный **STORY_STUDIO_SETUP.sql**, уже включающий v3. Не запускайте старый отдельный upgrade v1/v2 поверх v3. Целевая версия — `story_studio_version() = 3`, модерация — `1`.

Сборка: `npm run build:freedom-schema`. Проверки: `npm test`, `npm run test:sql` (4 набора), `npm run test:browser` (7 наборов; статический сервер на 8000). SQL-тесты выполняются на PGlite с pgcrypto, не на рабочих произведениях. Браузерные проверки используют локальный режим и тестовые сетевые ответы, а не аккаунт владельца. Состояние реального развёртывания — в [DEPLOYMENT_STATUS.md](DEPLOYMENT_STATUS.md).
