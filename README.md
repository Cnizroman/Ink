# ✒ Чернила — гигантская платформа для авторов

**«Чернила»** — тёмная литературная платформа для авторов рассказов, романов, повестей, стихотворений, эссе и всего, что пишется буквами. Место, где истории находят читателей, а авторы — друг друга.

> Никого не вспомнят. Пока он не напишет.

Платформа выросла из личного сайта **Cnizroman** «Никто не вспомнит»: автор стал основателем и первым автором «Чернил», а его тетралогия и «Белая голова» — первыми произведениями каталога. Секретные/пасхальные истории старого сайта полностью удалены.

- **Сайт:** https://cnizroman.github.io/Ink/
- **Стек:** HTML, CSS, JavaScript (SPA без сборки), Supabase (Auth + Postgres + Storage + RLS), GitHub Pages

## ✨ Что умеет платформа

**Для читателей**
- Каталог с фильтрами: тип (роман, рассказ, повесть, стихи, эссе, сборник, фанфикшн, пьеса, дневник), категория/жанр, статус и сортировка. Живой поиск по названию при вводе (без учёта регистра и различий е/ё); расширенный поиск также по автору, тегам и аннотации.
- Страница произведения: обложка, аннотация, статистика, главы, похожие произведения.
- Читалка: темы «Тьма / Бумага / Свет», размер шрифта, прогресс чтения, комментарии к главам.
- Личная полка: «Хочу прочитать», «Читаю», «Прочитано», «Избранное», продолжить чтение.
- Подписки на авторов и лента новых глав.
- Рецензии по фирменной системе пяти критериев (наследство проекта Cnizroman): сюжет — до 5, персонажи, атмосфера, язык и стиль, эмоции — до 4; **максимум 21 балл**.

**Для авторов**
- Профиль: выбор аватара и баннера с устройства, кадрирование и масштаб, акцент и цвета, компактный/развёрнутый вид, обращение, список соцсетей и настоящая OAuth-привязка поддерживаемых провайдеров, жанры, настройки отображения города и статистики, живой предпросмотр.
- Студия автора: только собственные произведения, сгруппированные в циклы; настоящие накопленные счётчики, черновики. Искусственного графика нет.
- Мастерская глав: выделения, диалоговые окна, примечания, спойлеры, списки, выравнивание, отмена/повтор, живой предпросмотр, локальное восстановление черновиков, цель по словам, поиск/замена, локальная история версий, шаблоны сцен, импорт TXT/MD/JSON, экспорт TXT/MD/JSON, цвета текста/подсветки, темы, ширина и раскладка рабочего места, режим фокуса. См. [WORKSHOP.md](WORKSHOP.md).
- Циклы и группы: дилогии, трилогии, тетралогии и серии; выбор существующих произведений, порядок чтения, редактирование состава и удаление группы без удаления книг. Раздел студии: `#/studio/groups`.
- Генератор обложек (градиенты и символы), теги, возрастной рейтинг, статусы.

**Для администратора** — выдача и отзыв произвольных значков/достижений, модерация, «Выбор платформы». Роль назначается владельцем в SQL Editor, не по юзернейму: [ADMIN_SETUP.md](ADMIN_SETUP.md).

## 🚀 Запуск локально

```bash
python -m http.server 8000
# http://localhost:8000
```

Вход основателя в локальном режиме: `cnizroman` / `demo1234`. Других произведений, кроме книг основателя, платформа изначально не содержит — остальные появятся только от настоящих зарегистрировавшихся авторов.

## 🗄️ Подключение Supabase (общая база)

Без настройки сайт работает на `localStorage`. Для общей базы выполните
[`supabase-platform-schema.sql`](supabase-platform-schema.sql). Затем подтвердите
свой аккаунт основателя через SQL Editor и разверните серверную функцию входа
по юзернейму по [ADMIN_SETUP.md](ADMIN_SETUP.md). До развёртывания функции в поле
входа принимается email. Публичный сайт не раскрывает почту по юзернейму.
Книги основателя встроены в код; изменяемые карточки сохраняются отдельно.
Подробности: [SUPABASE_PLATFORM_SETUP.md](SUPABASE_PLATFORM_SETUP.md).
**Для файлов профиля и реального OAuth нужна дополнительная настройка:**
[SOCIAL_AND_MEDIA_SETUP.md](SOCIAL_AND_MEDIA_SETUP.md). Секреты провайдеров
хранятся в Supabase, не в браузере.

Старая таблицы `reviews` и панель `reviews-admin.html` не трогаются и продолжают работать.

## Каталог без подстановок

Встроены только шесть текстов Cnizroman с полными исходниками в репозитории.
Фиктивные просмотры и сгенерированные главы-аннотации удалены: кнопка
«Читать полный текст» ведёт в авторскую читалку, а старые ссылки на тизеры
перенаправляются к исходнику. Статистика объёма тизеров не выдаётся за
объём книги. Новые реальные работы авторов и их черновики сохраняются.
Миграция `localStorage` удаляет только явно помеченные демо-записи и работы
встроенных демо-аккаунтов (`username@chernila.local` с демо-паролем),
не сбрасывая весь браузерный каталог.

«Никто не вспомнит» оформлен как тетралогия с отдельным прологом в начале
порядка чтения; «Белая голова» в этот цикл не входит. Автор может создать
группу из одной книги и дополнять её по мере публикации. Название типа
(например, трилогия) не ограничивает число текстов: допускаются прологи
и незавершённые циклы. Одна работа может входить в несколько групп.

## Проверки

- Без установки зависимостей: `node --test tests/*.test.cjs`.
- `npm ci` устанавливает только инструменты тестирования, не сборку сайта.
- `npm run test:sql` — полная схема в изолированном PostgreSQL (PGlite),
  повторный запуск миграции, Storage RLS (чужие папки недоступны для записи), защита от выдачи себе прав/значков.
- При запущенном `python -m http.server 8000 --bind 0.0.0.0`:
  `npm run test:browser` — Chromium, живой поиск, циклы, личные произведения,
  профиль, выдача/отзыв значков, мастерская, восстановление и публикация,
  импорт/экспорт и история версий, мобильная ширина. Отдельный mock-cloud
  сценарий проверяет бинарные загрузки, откат при ошибках, OAuth-редирект,
  возврат и отключение identity. Тесты не обращаются к настоящему Supabase
  и не авторизуют внешние реальные аккаунты.
  Браузерный набор рассчитан на Linux/Node 22+; зависимости сайта отсутствуют.
