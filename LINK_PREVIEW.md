# Превью ссылки «Чернил»

Основной адрес: https://cnizroman.github.io/Ink/.

## Что видят Telegram и другие сервисы

В статическом `<head>` главной страницы заданы Open Graph и Twitter Card:
название/описание платформы, canonical и `og:url` текущего сайта, абсолютный
HTTPS-адрес PNG 1200 × 630, тип изображения и альтернативный текст.
JavaScript и вход в аккаунт для получения этих данных не нужны.

- Карточка платформы: `assets/ink-social-card-v1.png`.
- Редактируемый векторный исходник: `assets/ink-social-card-v1.svg`.
- Пересборка: `npm ci && npm run assets:social-card`.
  Нужны системные шрифты DejaVu в `/usr/share/fonts/truetype/dejavu/`.
  Скрипт использует тестовый Chromium и только локальные ресурсы; генерация
  на стороне GitHub Pages не требуется, готовый PNG хранится в репозитории.
- Старое изображение `assets/og-image.png` осталось обложкой авторского цикла
  на отдельных книжных/архивных HTML-страницах. Оно больше не используется
  как изображение главной страницы платформы.
- Абсолютные метаданные старых HTML-страниц, `robots.txt` и `sitemap.xml`
  перенесены с прежнего `/Nobody-came/` на действующий `/Ink/`.

## Если в Telegram всё ещё старая карточка

Telegram кеширует превью независимо от кеша браузера и service worker сайта.
Ctrl+Shift+R на сайте не обновляет карточку сообщения в Telegram. Новое имя PNG
помогает после повторного чтения метаданных, но не принуждает Telegram перечитать
уже сохранённую страницу. Старые сообщения могут остаться со старым изображением.

Для проверки отправьте новую ссылку:

```text
https://cnizroman.github.io/Ink/?preview=ink-v1
```

Это обычная главная страница с новой строкой запроса. Такой URL может вызвать
новую загрузку превью; срок обновления кеша конкретного мессенджера сайт не
контролирует. Не добавляйте к ссылкам токены сессии или OAuth-параметры.

## Ограничение SPA

Маршруты вида `#/…` не отправляются HTTP-серверу. Ссылки на разделы/истории
внутри SPA получают общую статическую карточку платформы, а не персональные
метаданные произведения. Простое изменение `<meta>` после запуска JavaScript
этого не исправляет: Telegram не обязан выполнять код приложения. Отдельные
карточки таких историй потребуют статических share-страниц или серверного
рендеринга с проверкой публичности текста. Это обновление такого механизма
не добавляет и не раскрывает закрытые/неодобренные произведения.

## Проверка

`npm test` включает проверки метаданных без выполнения JavaScript, существования
ресурсов, фактических размеров PNG, совпадения Open Graph/Twitter image и
отсутствия старого адреса в статических метаданных. Фактическое обновление
карточки в приложении Telegram проверяет владелец после публикации.
