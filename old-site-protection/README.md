# Подготовленные файлы защиты старого сайта

Эти файлы предназначены только для репозитория `Cnizroman/Nobody-came`, который публикуется из `main`. Сначала сделайте приватную резервную копию файлов, которые собираетесь заменить или удалить. Не публикуйте пароль и резервные копии.

Архив для загрузки содержит `book3.html`, `reviews-admin.html`, `sw.js`. Загрузите все три файла в корень старого сайта с заменой существующих файлов, одним коммитом. При замене админки учитывайте, что она подготовлена из состояния репозитория на момент создания архива: если админку после этого редактировали, нужно объединить изменения вручную, а не перезаписывать их.

Чтобы текущий старый сайт не раздавал старый шифротекст, ключевые данные и открытое аудио, отдельно удалите из текущей версии репозитория `book3-gate.js`, `book3-vault.js`, `final-voice-with-shot-balanced-2.mp3`, `tools/book3-lock.mjs`. Не удаляйте `book3-final-voice.html`: он ведёт к защищённому входу. До удаления эти старые файлы остаются доступны напрямую. Удаление из текущей версии не удаляет Git-историю, внешние копии и ранее сохранённые данные. Изменений истории, переписывания коммитов или отключения сайта эта инструкция не предусматривает.

В админке старого сайта появится форма смены общего пароля обеих версий. Для её работы войдите под существующим аккаунтом владельца Ink. Сервер проверяет UUID владельца; вход просто любым администратором не выдаёт право изменять пароль. Минимум 5 символов, максимум 72 байта UTF-8. Не используйте старые коды или пароль аккаунта. Если пароль ещё не задан, установите его самостоятельно; автор архивов его не устанавливает.

Проверьте после публикации: неправильный пароль не открывает текст; новый пароль открывает обе версии; ссылка на аудио после удаления возвращает 404; форма отказывает не-владельцу; после обновления старого сайта новая версия service worker включена. Не вводите пароль в консоль или переписку. Офлайн-устройства и старые вкладки могут сохранять ранее полученные данные, а содержимое истории репозитория и скачанные копии остаются публичными.

Обёртка старого сайта показывает существующую защищённую читалку Ink внутри страницы без перенаправления. Обе версии используют один пароль и одну версию шифрованного текста и аудио; доступны только при работе сайта Ink и сервера Supabase. `sw.js` удаляет старые кеши `nobody-` и не подставляет устаревшие копии защищённых адресов при отсутствии сети.
